# Entropy
Entropy analysis tools cobbled together by vibe coding and pilfering from others. 
---
### Installation
```
$ python3 -m pip install --upgrade pip
$ pip3 install -r requirements.txt
```
---
### Usage
```
$ ./entropy.py 
usage: entropy.py [-h] [-o] [-l] [-g] [-r] [-c COMPFILE] [-x] input_file
entropy.py: error: the following arguments are required: input_file
```
---
### Help Menu
```
$ ./entropy.py -h
usage: entropy.py [-h] [-o] [-l] [-g] [-r] [-c COMPFILE] [-x] input_file

positional arguments:
  input_file            Input file

options:
  -h, --help            show this help message and exit
  -o, --output          Save output(s)
  -l, --clio            Preview first 2000 bytes
  -g, --graph           Show graphical represenation
  -r, --raster          Show bitraster representation
  -c COMPFILE, --compfile COMPFILE
                        Comparison file; outputs a bitraster
  -x, --xxd             Show hex representation
```
